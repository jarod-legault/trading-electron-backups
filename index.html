Trading Electron Backups

Trading Electron Backups is a personal backup tool operated by Jarod Legault. It uses rclone to access the owner's Google Drive and Restic to store encrypted database backups for recovery.

This tool is for the owner's own computers and Google account. It is not a public trading service and does not place orders or offer account access to other users.

Google Drive access allows the tool to create, list, read, and remove backup repository files. Restic encrypts database backups before they are uploaded.

Privacy policy

Trading Electron Backups · Updated October 3, 2026

This personal tool is operated by Jarod Legault to back up and recover databases on the owner's computers.

Google Drive access and use

The tool uses Google OAuth authorization through rclone to access the owner's Drive. Its configured Drive permission can permit access beyond the backup folder; the backup workflow uses the trading-electron-backups folder to create, list, read, restore, and remove encrypted backup repository files. It reads file metadata and repository contents as needed for those operations.

Storage and protection

Restic encrypts database snapshots and their manifests before uploading them to Google Drive. Local snapshots remain on the owner's computers. OAuth client credentials and access/refresh tokens are stored locally in configuration files. The separate Restic encryption password is stored locally outside the source repository. These credentials are not published on this website.

Sharing

The backup tool does not sell Google user data, use it for advertising, or share it with unrelated third parties. Google processes the uploaded encrypted files to provide Drive storage. Authorized backup and restore copies may be transferred between the owner's computers.

Retention and deletion

Backup retention is controlled by the owner's local and Restic retention settings. The owner can delete backups using the backup tools and revoke OAuth authorization in Google account settings. Revoking access prevents subsequent Drive operations but does not delete existing backups or local copies.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.
